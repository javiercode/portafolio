# Portafolio de Javier Canqui Llusco

Un portafolio interactivo de estilo retro y vintage que simula un sistema de escritorio virtual. Este proyecto ha sido adaptado y personalizado para mostrar la trayectoria profesional, habilidades técnicas, referencias y proyectos de **Javier Canqui Llusco** (Desarrollador de Software / Ingeniero de Inteligencia Artificial & Machine Learning).
